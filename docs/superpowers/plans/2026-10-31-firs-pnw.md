# FIRS PNW Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** FIRS PNW, a fork of FIRS 5.2.0 with a temperate "Pacific Northwest" economy carrying the user's aerospace, Product of Origin/EDEKA, shipbuilding and oil chains. Plus new PNW Transit vehicles for the new cargos.

**Architecture:** FIRS is Python that renders NML, which nmlc compiles to a GRF.
- **Fork:** the fork lives in `G:\dev\firs-pnw` (cloned at tag `5.2.0`, work on branch `pnw`). Industries, cargos and economies are one Python file each, under `src/industries`, `src/cargos` and `src/economies`.
- **New art:** rendered with coastal-grflink's voxel renderer into FIRS-format sprite sheets.
- **Vehicles:** the new vehicles go into coastal-grflink's `transit/` set.
- **Test harness:** `src/check_pnw.py`, a cargo-flow and flags checker for the PNW economy, plus a successful nmlc build.

**Tech Stack:** Python 3.14, nml (nmlc), chameleon, Pillow; coastal-grflink `common/render.py` and `common/newgrf`.

**Spec:** `docs/superpowers/specs/2026-10-31-firs-pnw-design.md`

## Global Constraints

- **GRF identity:** name "FIRS PNW", GRF ID `TFPI`, version string `5.2.0-pnw.N`, GPL v2. The FIRS credit is kept in the readme and the GRF description.
- **Economy:** id `PACIFIC_NORTHWEST`, the next free `numeric_id`, temperate climate.
- **New cargos**, as label → name:
  - `ACPT` Aircraft Parts
  - `ALUM` Aluminium (reuse FIRS `aluminium` if its label is already `ALUM`)
  - `ACFT` Aircraft
  - `ACFC` Certified Aircraft
  - `FLPL` Floatplanes
  - `SHIP` Ships
  - `JETF` Jet Fuel
  - `PODY` Product of Origin Dairy
  - `EGSW` EDEKA Gouda Sandwiches

  Each label must be unused in FIRS 5.2.0 and the OpenTTD cargo label list; check with grep before use.
- **Cargo classes:**
  - `PODY` has milk's classes (`CC_EXPRESS, CC_LIQUID_BULK, CC_POTABLE, CC_REFRIGERATED`).
  - `EGSW` has FIRS food's classes.
  - `JETF` has petrol's classes.
  - `ALUM` and `ACPT` have steel's and goods' classes respectively.
  - `ACFT`, `ACFC`, `FLPL` and `SHIP` are `CC_OVERSIZED` + `CC_PIECE_GOODS`.
  - The `ACFC` price factor is 1.5 × the `ACFT` one.
- **Scenario-only industries:**
  - The list: Dreamlifter Delivery Airport, Aluminium Smelter, Aircraft Assembly Plant, Aircraft QA Centre, Customer Acceptance Centre, Floatplane Factory, Seaplane Base, Oil Terminal.
  - `prob_map_gen="0"` and `prob_in_game="0"`.
  - Never close, regardless of FIRS's secondary-closure parameter.
  - Players can't fund them.
  - No location checks beyond what the tiles physically need (water for the seaplane base).
- **Every produced cargo in `PACIFIC_NORTHWEST` is accepted by some enabled industry,** and every accepted non-supply cargo is produced by one (`check_pnw.py`).
- **Art:** 8bpp OpenTTD palette only, rendered with `G:\dev\coastal-grflink\common\render.py`. Reuse FIRS's own art where FIRS already has the building: `oil_refinery.png` for the refinery, `aluminium_plant.png` for the smelter.
- **Install:** built GRFs go to `G:\Google Drive\Documents\OpenTTD\newgrf`.

## Review Focus

1. **A new cargo no vehicle can carry.** Expected: each one has a NARS wagon by class, or a PNW Transit vehicle (Task 9 test).
2. **Players funding a scenario-only industry, or one closing.** Expected: impossible (Task 7 checker).
3. **Sprite colours mangled** because the art isn't in the TTD palette. Expected: the art matches FIRS in-game (Task 8 palette assert).
4. **A new cargo label clashing with a NARS label.** Expected: the label is unique (Task 3 grep check).
5. **The GRF ID or name clashing with real FIRS.** Expected: both can be installed side by side (Task 1).
